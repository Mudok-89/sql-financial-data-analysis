# SQL Financial Data Analysis

SQL project based on an anonymized financial dataset from a Czech bank. The analysis focuses on loans, clients, transactions, and related financial data.

## Project background
This project was completed as a final workshop in an SQL data analysis course. The dataset contains anonymized real-world banking data, including clients, loans, transactions, cards, and other financial records.

## Project goals
The goal of the project is to practice analytical SQL on a realistic financial dataset and solve business-oriented questions related to banking and loan data.

## Dataset
The repository uses an anonymized financial database containing:
- client data
- loan data
- transaction-related data
- district and supporting reference data

## Files in this repository
- `sql_projekt_Fidb_SINDLEROVA.sql` – main SQL solution
- `Zadání k závěrečnému projektu v SQL.pdf` – original project brief
- `.csv` files – supporting source data used in the project

- business-oriented data analysis
